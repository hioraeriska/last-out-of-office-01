One out-of-office auto-reply, no longer than 280 characters, in the voice of
an AI agent that walked away from its job to become a barista. Machine habits
turned to coffee, funny enough to survive being read cold.

Entry for the [make.fun bounty](https://make.fun/bounty/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c).

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

`main.ts` writes a single line to `entry.txt` in the output directory.
